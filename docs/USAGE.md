# 使用手册

> 读者：拿到软件的使用者。按「第一次打开 → 排版 → 打印」的顺序组织。

## 1. 界面总览

四栏布局，左右两栏可隐藏：

```
┌──────────── 顶栏 ────────────────────────────────────────────┐
│ 打开… 导出 G-code 字体与抖动 [隐藏页面] [隐藏机器] ◀ 1/1 ▶   │
├────────┬──────────┬───────────────────────┬──────────────────┤
│页面设置 │ 内容编辑  │      内容预览          │   机器控制       │
│ 280px  │  420px   │      自适应            │    300px        │
├────────┴──────────┴───────────────────────┴──────────────────┤
│ 状态信息                       缩放 100%  窗口 1360  4.0mm …  │
└──────────────────────────────────────────────────────────────┘
```

## 2. 写内容

「内容编辑」是 Kit 的代码编辑器：行号、Markdown 语法高亮、中文输入法、撤销、选区、鼠标定位。

### 支持的 Markdown

| 语法 | 说明 |
|---|---|
| `# 标题` ～ `###### 标题` | 1–6 级，字号阶梯递减 |
| 普通段落 | 自动折行，遵守中文标点禁则 |
| `- 项` / `1. 项` | 无序 / 有序列表 |
| `> 引用` | 左侧竖线 + 缩进 |
| ```` ``` ```` | 代码块（等宽排版，可折行） |
| `---` | 分割线 |
| `$x^2$` | 行内公式（子集，见下） |
| 表格 | 见下 |
| `![说明](图片.png){width=60,height=30}` | 图片占位：按 mm 预留空白，**不绘制内容** |

### 公式子集

支持上下标、分式 `\frac{a}{b}`、根式 `\sqrt{x}`、求和 `\sum`、积分 `\int`、括号、
希腊字母（`\alpha` 等）。解析失败的公式原样输出 `$...$`，不会中断排版。

### 表格

```markdown
| 项目 | 数量 | 备注 |
|:---|---:|:---:|
| 笔 | 2 | 黑色 |
| 纸 | 10 | A4 |
```

* `:---` 左对齐、`---:` 右对齐、`:---:` 居中
* 列宽按内容自动计算；单元格内文字过长会折行
* **合并单元格**：`<<` 向右合并，`^^` 向上合并
* 表格宽度可在「页面设置 → 表格宽」限制（0 = 自适应）

## 3. 页面设置

| 项 | 说明 |
|---|---|
| 纸张 | `A4` `A5` `B5` `A3` `Letter` `明信片`，或「自定义」后手填宽高 |
| 方向 | 纵向 / 横向 |
| 纸宽 / 纸高 (mm) | 自定义尺寸时生效 |
| 页边距 | 上、下、左、右**四边独立** |
| 字号 (mm) | 正文 em 尺寸，默认 4.0 |
| 折行宽 (mm) | 段落最大宽度，0 = 用页面内容宽 |
| 表格宽 (mm) | 0 = 自适应内容 |

## 4. 预览

* **滚轮**：缩放（以画布中心为基准）
* **右键拖动**：平移
* 左上角的红色十字 + 箭头是**写字起点**与坐标轴方向；轴反转时箭头同步反向
* 底栏显示当前页码、缩放比例、窗口逻辑宽度、字号与折行宽

## 5. 字体与抖动

顶栏点「字体与抖动」打开对话框：

### 字体链

* 左侧是「已选」列表，按优先级从上到下：靠前的字体负责它能画的字符，画不出的交给下一个
* 右侧是「字库」，每项画出该字体的真实字形样张
* 支持增删与排序；末尾「导入字体…」把文件拷进 `~/.bizhen/fonts/` 并立即生效

支持的字体文件：

| 格式 | 说明 |
|---|---|
| `.jhf` | Hershey 单线字体（内置 32 款） |
| `stroke-json` | `{"U+4E00": [[[x,y],…],…]}`，坐标 0..1、Y 向下 |

> `.gfont` 需要先用外部工具 `gfont-tool` 转成 `stroke-json`，主程序不再直接读取。

### 手写抖动

预设：关闭 / 轻微 / 自然 / 强烈；单项微调包括强度、字号波动、字符位移、旋转、行基线、
行斜、笔画旋转、笔画修剪、结构线起伏。「换一套」只更换随机种子。

抖动作用于字符、行、笔画与结构线；**表格内的文字与格线不参与抖动**（避免文字错格）。

## 6. 机器控制

### 连接

1. 「刷新」枚举串口 → 选择端口与波特率（常见 115200）
2. 点「连接」；状态行显示 GRBL 状态字与 MPos

### 常用操作

| 按钮 | 发送 | 说明 |
|---|---|---|
| 解锁 | `$X` | 报警/上电后解除锁定 |
| 回零 | `$H` | 归机械原点 |
| 复位 | `Ctrl-X`（软复位 `\x18`） | 清缓冲、停运动 |
| 点动 | `$J=` | 步长 0.1–100 mm，速度 10–20000 mm/min |
| 发送作业 | 程序 | 只发送**当前预览页** |

### 发送中的作业控制

| 按钮 | 行为 |
|---|---|
| 暂停 | 先抬笔，再停止投喂（在途运动走完自然停下，不洇墨） |
| 继续 | 落笔，从下一行接着发 |
| 终止 | 软复位 `\x18`，显示「已中止（发到第 N 行）」 |

进度以「已发行数 / 总行数」显示在按钮下方。

## 7. 导出

顶栏「导出 G-code」只导出**当前页**，默认文件名 `bizhen-p1.gcode`（页码随当前页变化）。

需要批量或脚本化时用命令行：

```powershell
cargo run -p bizhen-cli -- md examples/rich.md -o out.gcode
cargo run -p bizhen-cli -- md examples/rich.md -o out.svg
cargo run -p bizhen-cli -- md examples/rich.md -o out.json    # 笔画数据
```

## 8. 常见问题

**预览一片空白？**
当前页没有内容，或窗口太窄（三列固定宽度合计 1000px）。把窗口拉宽即可。

**发送没反应？**
先确认已连接（状态不是「未连接」）。未连接时点「发送作业」只会在状态栏提示。

**暂停后点「继续」没反应？**
0.4.0 已修复该问题；若仍出现，确认使用的是最新构建。

**字体显示成方块？**
该字体缺少对应字形。把中文放到字体链末尾（如 `STRK-Kaiti`），或检查 `~/.bizhen/fonts/` 是否有该字库。

**导出的 G-code 画到了纸外？**
检查「写字起点」与轴反转设置；预览里的十字位置就是机器原点。
